# SOP-101: Crimp Height Out of Spec (SYNTHETIC EXAMPLE)
Applies to: terminal crimp stations on all lines.
Symptoms: crimp_height rejects rising above 1.5 percent of units, SPC chart trending toward a control limit.
Likely causes: worn crimp tooling, applicator shut height drift, terminal strip material lot change.
Steps:
1. Stop the station and quarantine the last 30 minutes of output.
2. Measure crimp height on 5 pieces with the micrometer and compare to the drawing tolerance.
3. Check applicator shut height and tooling wear. Replace tooling if wear exceeds the maintenance limit.
4. Verify the terminal lot number against the last known good lot.
5. Run 30 pieces and confirm in spec before releasing. Log the event with the root cause.
Escalate to the process engineer if the drift returns within one shift.
