# SOP-090: Changeover Checklist (SYNTHETIC EXAMPLE)
Applies to: all assembly lines.
Goal: keep changeover under the target time and confirm first article quality.
Steps:
1. Pre-stage tooling, material, and labels before the line stops.
2. Swap tooling using the quick-change checklist.
3. Load the new recipe and verify vision program version.
4. Run first article, inspect, and get quality sign-off.
5. Record start and end time in the downtime log.
